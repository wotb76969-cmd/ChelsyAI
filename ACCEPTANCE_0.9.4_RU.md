# Статус приёмки 0.9.4

Инженерная версия для отдельного испытательного Host. Полная приёмка по ТЗ открыта.

| Испытание | Фактический результат |
|---|---|
| Адаптация языка | Qwen2.5-0.5B-Instruct, LoRA на 16 синтетических примерах. По 4 примера в validation/test. Средняя ошибка на тесте 2,73 → 2,54. Конфигурация и хеши — в training/language/adapter/metrics.json. |
| Реальный Host и модель | В сохранённом прогоне до исправления PDF сервер вернул HTTP 200 для 99/150 функциональных запросов (71/100 RU, 28/50 EN) и вернул документ в 16/50 файловых сценариев (8 TXT, 8 DOCX). Независимая оценка содержимого отсутствует. Порог 90% не достигнут. |
| Форматы и изоляция пользователей | Предыдущие проверки генераторов на заданной структуре прошли 50/50. Отдельная матрица API на локальных HTTP и SQLite — 115/115. В поставке лежат пять примеров из проверки генераторов. |
| PDF | Исправлена обработка локального масштаба первой страницы в файлах fpdf2. На контрольном PDF проверено открытие, словарь действий при открытии по-прежнему отклоняется. Полный прогон модели после правки не выполнялся. |
| Кабинет и резервная копия | Вход, изменение профиля, перезагрузка и выход проверены на локальном HTTPS при ширине 320, 768 и 1440 px. На тестовых данных проверены сохранение UUID, восстановление SQLite и пользовательского ключа. |
| Нативные клиенты | Windows-инсталляторы собирались в CI на более ранней ревизии. Подпись финальных EXE не подтверждена. Сборка Android остановилась на отсутствии штатного release-keystore. iOS-target собрался в режиме симулятора. Подписанный IPA и испытания на физическом iPhone/Huawei отсутствуют. |

В исходном комплекте есть маршруты прежних клиентов и миграционные утилиты. Единый установщик Host со всеми компонентами, шифрование всех старых хранилищ, перенос реальной облачной базы, полная проверка стандартов безопасности и сроков удаления остаются незакрытыми. Примеры, фикстуры и локальные испытания описывают проверенные сценарии текущей разработки.
