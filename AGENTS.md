# Chelsy AI 0.9.4

Chelsy — личный помощник с собственным HTTPS Host. Host отвечает за аккаунты, локальную модель, данные владельца и создание документов. Требования и критерии готовности находятся в [ТЗ](docs/0.9.4/ТЗ_Chelsy_AI_0.9.4.docx).

- **Host и данные.** Python и SQLite в `ChelsyAI_0.9_Windows/`. Вход и сессии — `auth/`, API кабинета — `api_v3.py`, версионированные изменения БД — `migrations.py`. Сохраняй UUID и принадлежность данных.
- **Модель.** В `mind/` находятся маршрутизатор и генераторы файлов. Корпус, веса маршрутизатора и код обучения — в `training/`; компактный LoRA для Qwen2.5-0.5B-Instruct — в `training/language/`. Локальный запуск поддерживает Ollama или Transformers с PEFT.
- **Клиенты.** Windows использует Tkinter. Android и iOS используют общий Flutter-проект `Android_Client/`. Веб-кабинет — `ChelsyGroup_Web/`.
- **Запуск и проверка.** Из каталога Host в настроенном окружении: `python host_server.py`; точечная проверка: `python -m unittest test_auth094`; общий набор: `python -m unittest discover`. Из каталога Flutter: `flutter analyze`, `flutter test`. Порядок настройки — [в инструкции](INSTALL_0.9.4_RU.md).
- **Рабочий порядок.** Начинай с этого файла и `git diff`, затем ищи нужный символ через `rg`. Правь связанный код в отдельной ветке, запускай затронутые проверки, открывай PR. Перед установкой нового пакета объясни назначение и дождись подтверждения. Скачивание больших моделей и ресурсоёмкое обучение требуют отдельного разрешения. Используй локальные инструменты без платных API. Секреты, базовые веса и временные данные должны оставаться вне Git.
- **Этап.** Идёт приёмка 0.9.4. Маршрутизатор и небольшой адаптер обучены. Метрики и открытые ограничения — в [сводке](ACCEPTANCE_0.9.4_RU.md). Изменяй её только по результатам нового испытания.
