# Chelsy AI 0.9.4 — модель угроз (этап 1)

Метод: STRIDE по границам доверия + OWASP Top 10 for LLM Applications (2025). Нумерация угроз `T-xx` используется в матрице стандартов (`03_МАТРИЦА_СТАНДАРТОВ.md`).

## Активы

1. Частное содержимое: диалоги, память, файлы, embeddings, персональные адаптеры.
2. Учётные данные: хеши паролей, refresh/access-токены, код восстановления, ключи данных (DEK/KEK).
3. Административные права (ровно два администратора), журнал аудита.
4. Целостность модели: веса маршрутизатора, адаптер LoRA, реестр кандидатов.
5. Доступность Host: GPU/CPU/RAM/диск, очередь задач.

## Границы доверия

B1 интернет/LAN → Gateway (HTTPS) · B2 Gateway → Mind/модель · B3 модель → инструменты/Artifact Builder · B4 панель Host (локально) → Gateway · B5 ОС Host → процесс Chelsy · B6 внешний контент (сайты, документы) → контекст модели.

## Угрозы

| ID | Граница | Угроза (STRIDE / LLM) | Мера | Остаточный риск |
|---|---|---|---|---|
| T-01 | B1 | Перебор паролей, credential stuffing (S) | Лимиты аккаунт+IP / IP / сервис, временные задержки, Argon2id, проверка слабых паролей | Медленный распределённый перебор; MFA не используется по решению ТЗ (AAL1) |
| T-02 | B1 | Кража/повтор refresh-токена (S, E) | Ротация, обнаружение повторного использования → отзыв семейства, хранение только хеша | Токен на взломанном устройстве действует до 10 мин (access) |
| T-03 | B1 | CSRF в веб-кабинете (T) | SameSite=Strict cookie + CSRF-токен в заголовке + проверка Origin | — |
| T-04 | B1 | XSS в кабинете → кража сессии (I) | CSP без unsafe-eval/inline-script, экранирование, HttpOnly cookie | Ошибка в шаблоне до ревью |
| T-05 | B1 | IDOR: чужой UUID диалога/файла (I) | Проверка владельца в SQL каждого запроса; тесты с чужими ID | — |

| T-07 | B4 | Администратор читает чужое содержимое (I, E) | Нет таких маршрутов; RBAC в коде; аудит; шифрование DEK под ключом пользователя | Оператор ОС (T-20) |
