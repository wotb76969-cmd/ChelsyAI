# Chelsy AI 0.9.4 — матрица стандартов (SEC-01)

Зафиксированные версии на старте (2026-11-17):
* OWASP ASVS 5.0 — профиль L2 для веб/API там, где применимо;
* OWASP MASVS 2.x / MASWE;
* OWASP Top 10 for LLM Applications 2025;
* NIST AI RMF 1.0 + Generative AI Profile (NIST AI 600-1);
* NIST SP 800-63B-4 — вход только по паролю, поэтому **профиль AAL1**, а не AAL2;
* требования Android (Play/Huawei AppGallery), Apple App Review, Microsoft (подпись Authenticode).

Статусы: **план** — не начато · **реализовано** — код есть · **проверено** — есть автоматическая или ручная проверка с доказательством · **исключение** — осознанное расхождение.
Матрица обновляется в конце каждого этапа. Отчёт о выпуске ссылается на её итоговую версию.

## Заранее известные исключения

| Контроль | Расхождение | Компенсирующие меры | Остаточный риск |
|---|---|---|---|
| ASVS V6.4 (MFA) / 800-63B AAL2 | Вход только по паролю по требованию ТЗ; MFA нет, в том числе для администраторов | AAL1-профиль: длинные пароли, лимиты, короткие админ-сессии, панель только на 127.0.0.1, аудит, двойное подтверждение изменений состава | Компрометация пароля администратора даёт управление сервисом, но не содержимое пользователей (SEC-04) |
| Защита от оператора ОС Host | Host обрабатывает данные в открытом виде в памяти | Шифрование на диске, RBAC, раскрытие ограничения | Оператор ОС может читать память процесса |
| Подтверждение email | Своей почты нет: саморегистрация и восстановление по почте выключены | Аккаунты создают администраторы; первичный пароль одноразовый, со сменой при входе | Неудобство регистрации |
| 152-ФЗ / GDPR | Применимость не определена (нет юрисдикции) | Минимизация данных, экспорт и удаление в кабинете | Соответствие не заявляется |
